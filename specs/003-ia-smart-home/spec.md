# Feature Specification: AI-Smart Home & OKR Copilot

**Feature Branch**: `003-ia-smart-home`  
**Created**: 2026-03-16  
**Status**: Draft  
**Input**: User description: "vamos deixar a tela de início funcional. quero que o campo de imput seja um atalho orientado por ia... wizard para cadastro... tela inicial como copilot com notificações dinâmicas."

## User Scenarios & Testing *(mandatory)*

### User Story 1 - SMART OKR Generation via SmartPrompt (Priority: P1)

As a User, when I type a vague goal (e.g., "Melhorar satisfação") into the SmartPrompt, I want the AI to instantly propose a SMART alternative (e.g., "Aumentar eNPS de 65 para 75 até Dez/2026"), so I can create high-quality strategic goals without manual effort.

**Why this priority**: Core "wow" factor and primary entry point for AI-assisted strategy.

**Independent Test**: Use the SmartPrompt to type "Reduzir custos" and verify an AI Suggestion Card appears with a specific, measurable version.

**Acceptance Scenarios**:

1. **Given** I am in the SmartPrompt, **When** I type "Reduzir turnover", **Then** the AI suggests "Reduzir turnover voluntário de obra de 3,36% para 3% em 6 meses".
2. **Given** an AI suggestion, **When** I click "Aceitar e Continuar", **Then** I am navigated to the creation Wizard with fields pre-populated.

---

### User Story 2 - Smooth OKR Creation Wizard (Priority: P2)

As a User, after accepting an AI suggestion, I want to be guided through a step-by-step wizard to define Owners, Weights, and Dimension, so that the complex setup process is broken down into simple tasks.

**Why this priority**: Simplifies the administrative overhead of strategic planning.

**Independent Test**: Complete the wizard after an AI suggestion and verify the OKR is saved with all structural data.

**Acceptance Scenarios**:

1. **Given** the Wizard is open, **When** I proceed through steps (Define Owners -> Set Weights -> Confirm), **Then** the final summary reflects all inputs before saving.

---

### User Story 3 - Copilot Landing with Dynamic Agent Insights (Priority: P1)

As a User, when I access the home screen, I want to see a dynamic feed of "AI Agent" notifications (e.g., "O KR de Vendas está em risco devido ao atraso na Ação X"), so I can proactively manage the strategy.

**Why this priority**: Elevates the platform from a "Dashboard" to an active strategic "Co-pilot".

**Independent Test**: Verify the "Feed do Agente" shows mock/real notifications based on current OKR health.

**Acceptance Scenarios**:

1. **Given** the Home page, **When** I scroll to the Insights section, **Then** I see notifications with actionable advice (e.g., "Agendar check-in urgente").

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: SmartPrompt MUST integrate with an AI service (mocked or real) to generate SMART suggestions from natural language.
- **FR-002**: System MUST display AI suggestions as interactive cards below the input field.
- **FR-003**: System MUST implement a multi-step Wizard for OKR creation (Stage: Draft -> Configure -> Confirm).
- **FR-004**: Home page layout MUST resemble a Copilot interface (Central prompt, side/bottom insights, and dynamic notification feed).
- **FR-005**: AI Notifications MUST be dynamic and contextualized to the user's current OKR health/status.

### Key Entities *(include if feature involves data)*

- **AI Suggestion**: Temporary data object containing proposed Goal, Target, and Deadline.
- **Agent Notification**: Event-based insight generated by the AI agent logic.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Users can transform a vague goal into a saved SMART OKR in under 60 seconds using the AI flow.
- **SC-002**: 90% of AI suggestions are accepted by the user (simulated/tracked).
- **SC-003**: The Home page renders initial agent insights in under 500ms.
