# Quickstart: Restructured Dashboard

## Setup
1. Switch to branch `001-add-home-page`.
2. Ensure dependencies are installed (`npm install`).

## Development
- The main entry point is now `src/presentation/pages/Home.tsx`.
- The executive dashboard is at `src/presentation/pages/Overview.tsx`.
- Sidebar configuration resides in `src/presentation/layouts/AppLayout.tsx`.

## Key Files to Watch
- `src/App.tsx`: Route definitions.
- `src/presentation/layouts/AppLayout.tsx`: Sidebar links and icons.
- `src/presentation/pages/Home.tsx`: Center-piece for SmartPrompt.
- `src/presentation/pages/Overview.tsx`: New home for executive charts.
